Rapid Pi 0.9.8 is Pi 1.4.0, compiled ahead of time. Everything else is [0.9.7](0.9.7.md).

### Pi 1.4.0

- **Summaries without a fixed output cap:** compaction and branch summaries use the model's output limit, so long reasoning no
  longer makes them fail.
- **Codemode waits for a free worker:** parallel scripts and in-process subagents queue instead of failing, and
  `PI_CODEMODE_MAX_WORKERS` raises the limit.
- **Image input for classifiers**, a **Models Configuration reference** generated from the `models.json` schema, and support
  for the **Rex terminal** (OSC 8 hyperlinks, truecolor, inline images).
- **Windows shells:** Microsoft Store shell aliases work, and PowerShell and WSL's `bash.exe` are found when Windows is not in
  `C:\Windows`.
- Fixes to the terminal's state when pi exits abnormally, sessions after a response cut off at the output limit, `/compact`
  instructions, extension dialogs shown at the same time, Markdown bold and italic next to CJK punctuation, `grep` following
  `RIPGREP_CONFIG_PATH`, GitHub Copilot requests over its size limit and more: Pi's
  [1.4.0 changes](https://github.com/earendil-works/pi/releases/tag/v1.4.0).

### Rapid Pi

- The model catalog is Pi 1.4.0's, and the training profile is recorded for Pi 1.4.0.

### Engine

The runtimes are 0.9.7's: the engine has not changed.

### Install

```bash
curl -fsSL https://rapid-pi.opensec.in/install.sh | sh
```

```powershell
irm https://rapid-pi.opensec.in/install.ps1 | iex
```

```bat
powershell -c "irm https://rapid-pi.opensec.in/install.ps1 | iex"
```

or `rapid-pi update`, or `npm install -g --allow-scripts=rapid-pi rapid-pi`, or `bun add -g --trust rapid-pi`.
