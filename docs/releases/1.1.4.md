Rapid Pi 1.1.4 is [1.1.3](1.1.3.md) with an opt-in background service for remote control, so a paired phone reaches
this computer with no terminal open. Pi is still 1.5.0, and the engine and runtimes are 1.1.1's.

### Added

- **`rapid-pi service`** ([#262](https://github.com/opensec-git/Rapid Pi/pull/262)): `rapid-pi service install` starts
  remote control at login and keeps it up:
  - macOS: a LaunchAgent;
  - Linux: a systemd `--user` unit;
  - Windows: a per-user logon task, with no admin needed.

  The other subcommands:
  - `status` shows the addresses, the tunnel and the connected phones;
  - `pair` pairs a new phone from a terminal while the service runs;
  - `logs` prints the service log;
  - `uninstall` removes everything it wrote.

  Behaviour:
  - Paired phones can list this computer's projects and sessions, open one, or start a new session in a folder
    Rapid Pi already knows.
  - The Cloudflare tunnel follows `remoteControl.tunnel` (`install --no-tunnel` keeps it to the LAN and Tailscale).
  - The service sends paired phones its current addresses over the encrypted session, so a phone follows a quick
    tunnel's new address. No outside lookup service is involved.
  - When `/remote-control` starts in a terminal, the service hands over its port and tunnel and takes them back
    afterwards.
  - Only phones that are already paired can connect.
  - Interactive startup is unchanged: the service code loads only when it runs.

Also since 1.1.3, outside the release archives:

### Install

```bash
curl -fsSL https://rapid-pi.opensec.in/install.sh | sh
```

```powershell
irm https://rapid-pi.opensec.in/install.ps1 | iex
```

```bat
powershell -c "irm https://rapid-pi.opensec.in/install.ps1 | iex"
```

or `rapid-pi update`, or `npm install -g --allow-scripts=rapid-pi rapid-pi`, or `bun add -g --trust rapid-pi`, or:

- Homebrew (macOS on Apple silicon, Linux): `brew install opensec-git/tap/rapid-pi`
- Scoop (Windows): `scoop bucket add opensec-git https://github.com/opensec-git/scoop-bucket`, then `scoop install opensec-git/rapid-pi`
- mise: `github:opensec-git/Rapid Pi` with the options in the [installation guide](https://rapid-pi.opensec.in/docs/installation.html)

The installer checks the release signature with OpenSSL 3, `ssh-keygen` (OpenSSH 8.1 or later), or an installed Rapid Pi.
Every archive also has a GitHub build attestation: `gh attestation verify <file> -R opensec-git/Rapid Pi`.
