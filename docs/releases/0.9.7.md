Rapid Pi 0.9.7 updates itself on Windows without PowerShell. Everything else is [0.9.6](0.9.6.md).

### Fixes

- **Windows: `rapid-pi update` is no longer stopped by antivirus as a trojan** ([#82](https://github.com/ylstack1/RapidPi/issues/82)).
  Until now the update started the installer as `powershell -Command "irm .../install.ps1 | iex"`: a program starting
  PowerShell to download a script and run it, which is what malware "download cradles" do, and behavior-based antivirus
  stopped it as such (Kaspersky's System Watcher reported `PDM:Trojan.Win32.Generic` for `rapid-pi.exe`). Rapid Pi now updates
  itself: it checks the release's signed checksums with the release key, downloads the build from npm or else GitHub and checks
  it against them, unpacks it with Windows' own `tar.exe`, keeps the build it replaces for `rapid-pi update --rollback`, and
  puts the new files in place as the installer does. An installation outside your profile (a `RAPIDPI_INSTALL` such as
  `C:\tools\rapid-pi`) still updates through the installer, which manages that folder's permissions.

The fix is in the updater, so it takes effect from the update after this one: 0.9.4 to 0.9.6 still update to 0.9.7 the old
way. If antivirus stops that, install 0.9.7 with the installer from PowerShell (`irm https://rapid-pi.opensec.in/install.ps1 | iex`),
from the release's `rapid-pi-win32-x64.zip`, or with npm (`npm install -g --allow-scripts=rapid-pi rapid-pi`).

Pi is 1.3.0, as in 0.9.6. The engine is unchanged.
