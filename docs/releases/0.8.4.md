Rapid Pi 0.8.4 lets Rapid Pi and Pi share one setup without getting in each other's way, and makes installing on Windows smoother.
Everything else is [0.8.3](0.8.3.md).

### Pi and Rapid Pi side by side

- **Rapid Pi never changes the packages Pi loads.** Both use `~/.pi/agent` (logins, models, settings, sessions). Until you
  install or remove a package with `rapid-pi`, Rapid Pi loads the packages in `settings.json` as Pi does; the first such change
  gives Rapid Pi a list of its own (`rapidPi.packages`, made from Pi's) and changes only that. A package you install with
  `rapid-pi install` is Rapid Pi's; one you install with `pi install` is Pi's.
- **OpenSec's extensions load in Rapid Pi only.** `opensec-pi-subagents`, `opensec-pi-todo` and `opensec-pi-fff` are built for
  Rapid Pi's runtime, and Pi on Node cannot load them. Earlier installers added them to the list Pi reads too, so Pi started
  with "Failed to load extension" for each. Rapid Pi moves them to its own list as it starts, and the installers have it do so
  right after installing: update Rapid Pi (`rapid-pi update`) and Pi starts cleanly again.
- [README: Pi and Rapid Pi side by side](../../README.md#pi-and-rapid-pi-side-by-side).

### Windows

- The install commands are `irm https://rapid-pi.opensec.in/install.ps1 | iex` in PowerShell and
  `powershell -c "irm https://rapid-pi.opensec.in/install.ps1 | iex"` in Command Prompt. The longer command the README and the
  site showed for a day, which turned TLS 1.2 on first, was blocked by Microsoft Defender; an older Windows 10 that needs TLS
  1.2 for the first download has two lines on the docs' Installation page.
- Installing or updating from a PowerShell 7 prompt works: `install.ps1` uses Windows PowerShell's own modules first (thanks to
  @Vlyn, #14).

### Releases

- A `publish` run again for a release, to put the site and the installers up again, skips the `rapid-pi` version npm has.

### Engine

Unchanged since 0.8.3: this release's runtimes are [0.8.3's](0.8.3.md#the-runtimes).

### Install

```bash
curl -fsSL https://rapid-pi.opensec.in/install.sh | sh
```

```powershell
irm https://rapid-pi.opensec.in/install.ps1 | iex
```

```bat
powershell -c "irm https://rapid-pi.opensec.in/install.ps1 | iex"
```

or `rapid-pi update`, or `npm install -g --allow-scripts=rapid-pi rapid-pi`, or `bun add -g --trust rapid-pi`.
