Rapid Pi 0.8.7 runs in editors: `rapid-pi --acp` serves the Agent Client Protocol. Everything else is [0.8.6](0.8.6.md).

### Editors

[Agent Client Protocol](https://agentclientprotocol.com) (ACP) editors start Rapid Pi and show it in their agent panel: Zed,
JetBrains IDEs, VS Code (through an ACP extension), Neovim, Emacs and the other ACP clients. It is built in; point the editor at
`rapid-pi` with the argument `--acp`. In Zed's `settings.json`:

```json
"agent_servers": {
  "Rapid Pi": { "type": "custom", "command": "/full/path/to/rapid-pi", "args": ["--acp"], "env": {} }
}
```

- **Your Pi setup:** each editor session is a Pi session with your settings, models and logins, extensions, skills, prompt
  templates, context files and `mcp.json`.
- **Streaming replies and thinking**; **tool calls** with their kind and the files they touch, edits and writes as diffs, and
  command output while it runs (in Zed, in a terminal view with colours).
- **Model and thinking level** as session settings; extension commands, prompt templates, skills, `/compact` and `/name` as slash
  commands; context usage and cost after each prompt.
- **Sessions** are Pi's own session files: the editor lists them, opens one with its history or continues it, and a session
  started in the editor opens in the terminal with `rapid-pi --session <id>`.
- **The editor's MCP servers** connect next to those of `mcp.json`.
- **Extension dialogs** reach the editor: confirm and select as permission requests, input and editor as forms, notify as notices.

The ACP code loads only with `--acp`: the terminal UI, `-p` and RPC mode start and run as in 0.8.6. Setting up other editors:
[docs/ACP.md](https://github.com/opensec-git/Rapid Pi/blob/rapid-pi/docs/ACP.md).

### Install

```bash
curl -fsSL https://rapid-pi.opensec.in/install.sh | sh
```

```powershell
irm https://rapid-pi.opensec.in/install.ps1 | iex
```

```bat
powershell -c "irm https://rapid-pi.opensec.in/install.ps1 | iex"
```

or `rapid-pi update`, or `npm install -g --allow-scripts=rapid-pi rapid-pi`, or `bun add -g --trust rapid-pi`.

| Asset | For |
|---|---|
| `rapid-pi-linux-x64.tar.xz` / `.tar.gz` | **Recommended on Linux.** CPUs with AVX2 (Intel Haswell 2013+, AMD Zen+). |
| `rapid-pi-linux-x64-baseline.tar.xz` / `.tar.gz` | Any x86-64 CPU with SSE4.2. |
| `rapid-pi-linux-x64-jit.tar.xz` / `.tar.gz` | JIT also on, for plugins loaded at run time. |
| `rapid-pi-darwin-arm64.tar.xz` / `.tar.gz` | **macOS.** Macs with Apple silicon, macOS 13 or later. |
| `rapid-pi-darwin-arm64-jit.tar.xz` / `.tar.gz` | macOS, JIT also on. |
| `rapid-pi-win32-x64.zip` | **Windows.** Windows 10 (1809) or 11 on x64; compiled code on AVX2 CPUs, bytecode on others. |
| `rapid-pi-win32-x64-jit.zip` | Windows, JIT also on. |
| `rapid-pi-runtime-linux-x64.tar.gz`, `rapid-pi-runtime-darwin-arm64.tar.gz`, `rapid-pi-runtime-win32-x64.zip` | The Rapid Pi Bun runtime, for compiling plugins in. |

Linux x86-64 with glibc 2.17 or later; macOS 13 or later on Apple silicon; Windows 10 1809 or later, or Windows 11, on x64.
